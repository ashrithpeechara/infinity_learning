This directory contains cloud security research, offensive security labs, attack simulations, privilege escalation scenarios, enumeration techniques, and cloud-native exploitation methodologies across major cloud providers.

The content is organized based on:

* Cloud Providers

# Tactics

The repository includes cloud attack scenarios mapped across multiple offensive security tactics.

| Tactic               | Description                                       |
| -------------------- | ------------------------------------------------- |
| Initial Access       | Gaining initial foothold into cloud environments  |
| Persistence          | Maintaining long-term access                      |
| Privilege Escalation | Escalating permissions and roles                  |
| Enumeration          | Enumerating identities, permissions, and services |
| Recon                | Discovering exposed resources and attack surfaces |
| Credential Access    | Accessing tokens, keys, secrets, and credentials  |
| Discovery            | Discovering cloud assets and relationships        |
| Defense Evasion      | Bypassing detections and monitoring               |
| Execution            | Remote command execution and workload abuse       |
| Data Exfiltration    | Extracting sensitive cloud data                   |
